# East Potomac Park Tracker

An independent public-interest tracker focused on East Potomac Park and Hains Point in Washington, D.C.

The project was created to make it easier to follow public developments affecting the park, including news coverage, court activity, government action, public-interest trends, and other material developments relevant to the future of the site.

## Live Site

The project is published through GitHub Pages:

**East Potomac Park Tracker**  
https://tbilkitty.github.io/East-Potomac-Park-Tracker/

## What the Tracker Does

The site is designed to bring several categories of information into one place:

- Recent news concerning East Potomac Park and Hains Point
- Court and legal developments
- Public-interest and search-trend information
- Selected government or policy developments
- Email-signup and public-engagement features
- Automated content updates through GitHub Actions

The goal is not to collect every article mentioning Washington, D.C. or federal parkland. The project is intentionally focused on developments that are directly relevant to East Potomac Park and Hains Point.

## Why This Project Exists

East Potomac Park is a distinctive public landscape with recreational, environmental, historical, and civic value. Changes affecting the park can involve overlapping questions of federal land management, public access, administrative authority, congressional action, and community interest.

This tracker was created as a simple public-facing tool for following those developments without requiring users to search across multiple sources.

## Automation

The repository includes scripts and GitHub Actions workflows that periodically update selected site content.

Automated collection is used to reduce manual maintenance, but automated results may occasionally require review or correction. The project therefore should be treated as an informational tracker rather than an official government record.

The tracker may draw from public sources such as:
